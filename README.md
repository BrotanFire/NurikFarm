# NurikFarm
Контроллер автоматического полива на ESP32. Управление через бота ВКонтакте, локальный OLED-дисплей, шесть независимых каналов.

# Возможности
- 6 каналов полива с индивидуальными порогами срабатывания
- Управление через VK Long Poll (клавиатура, без ручного ввода команд)
- Настройка порогов и интервала опроса прямо из бота
- Энергонезависимое хранение настроек (NVS)
- OLED 128×32 (SH1106) — статус датчиков и лог событий
-Неблокирующий конечный автомат полива
- Защита от сбоев: watchdog 60 с, переподключение Wi-Fi, повторная синхронизация NTP

# Аппаратная часть
- ESP32 DevKit V1	30 pin
- Ёмкостные датчики влажности	6 шт., аналоговый выход
- Релейный модуль 12 В	6 каналов, active-LOW
- OLED 128×32	I2C, контроллер SH1106
- Блок питания 12 В	≥2 А, для реле и ESP32
Пины
GPIO	Назначение
19, 18, 5, 17, 16, 4	Реле 1–6
36, 39, 34, 35, 32, 33	Датчики 1–6 (ADC1)
22	OLED SDA
21	OLED SCL


# Настройка
Секреты вынесены в secrets.h (не коммитится). Шаблон — SecretsExample.h:
```
cpp
#define WIFI_SSID_SEC   "your_wifi_ssid"
#define WIFI_PASS_SEC   "your_wifi_password"
#define VK_TOKEN_SEC    "your_vk_token"
#define GROUP_ID_SEC    "your_group_id"   // без минуса
```
Для бота ВК: включить Long Poll API версии 5.199, разрешить сообщения сообщества и подписку на входящие события.


Логика работы
Интервал опроса по умолчанию — 60 минут. При срабатывании датчика (значение выше порога) запускается цикл: реле включается на 4 секунды, затем пауза 2 минуты для стабилизации показаний. Если порог не достигнут, цикл повторяется, но не более 6 раз. После успешного полива датчик помечается как политый до конца дня. Смена дня сбрасывает флаги полива.

Сборка
Arduino IDE 2.x, ядро ESP32 3.x (ESP-IDF 5.x). Библиотеки: U8g2 (oliver), ArduinoJson (Benoit Blanchon). Остальные (WiFi, HTTPClient, WiFiClientSecure, Preferences, Wire, time) входят в ядро ESP32.
